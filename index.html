UPDATE FIRMWARE

Update firmware sekarang lewat WiFi, bukan lewat halaman ini. Caranya:

1. Di perangkat: buka menu GLOBAL > UPDATE FIRMWARE, klik encoder untuk menyalakan WiFi.
2. Di HP: pindah sambungan WiFi ke DLMS-UPDATE (password dlms1234).
3. Buka browser, ketik 192.168.4.1, lalu upload file firmware .bin aplikasi (bukan merged/bootloader/partitions).
4. Setelah selesai, perangkat restart otomatis dan WiFi mati sendiri — sambungkan lagi HP ke WiFi biasa.

Audio senyap selama WiFi menyala dan selama proses update. Layar perangkat menampilkan SSID, password, dan progress update.
